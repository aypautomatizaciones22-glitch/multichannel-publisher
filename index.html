# MultiChannel Publisher Automation Welcome to the official website of MultiChannel Publisher Automation. ## About the Application MultiChannel Publisher Automation is a content distribution tool designed to help authorized account owners manage the publication of video content across supported social media platforms. The workflow uses n8n and Fliki's API to generate and distribute videos from scripts provided by the content owner.
